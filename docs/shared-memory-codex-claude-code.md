Started a task in Claude Code and continuing in Codex? Einstein Free gives both agents access to the saved conversations on one computer. An earlier decision is found no matter which agent you discussed it with.

## When it helps

- One agent ran out of its limit, and you switch to the other.
- One agent researched the problem, and the other helps with the implementation.
- You need a command or an agreement from a conversation in the other tool.

## Example of a hand-off

*“Find the discussion of [task name] with the other agent. Which solution did we choose and what is left to do?”*

## What is free

Search across your local Codex and Claude Code history and hints for both agents. No account, no subscription and no API key. Packages for Mac with Apple Silicon and for Windows 10/11.

Free works on one computer. Pro adds the Fact Map and the Plan Map, which you can open in the browser after signing in. Pro is currently free.
